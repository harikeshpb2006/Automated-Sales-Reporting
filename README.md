# Automated Sales Reporting Dashboard

## Project Overview

This project is an automated sales reporting dashboard developed using **MySQL** and **Microsoft Power BI**.

The dashboard provides an interactive view of sales performance and helps analyze revenue, profit, orders, products, customers, regions, and salespersons.

## Tools Used

- MySQL
- MySQL Workbench
- Microsoft Power BI
- SQL
- DAX

## Dashboard Features

The Power BI dashboard includes:

- Total Revenue
- Total Profit
- Total Orders
- Total Quantity
- Profit Margin
- Monthly Revenue Trend
- Revenue by Category
- Revenue by Region
- Salesperson Performance
- Product Performance
- Customer Performance

## Data Analysis

The project calculates:

- Revenue
- Total Cost
- Profit
- Profit Margin
- Monthly sales performance
- Category performance
- Regional performance
- Salesperson performance
- Product performance
- Customer performance
